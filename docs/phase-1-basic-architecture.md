## The Goal

In the first phase - lets settle on a basic chat-application architecture. It should be nothing more than a very elementary composition of all the foundational stack choices - setting us up for further experiments.

### Scope:

- BetterAuth in place - with a basic login screen
- Basic SQLite conversation storage
- Basic AI SDK Agent - with a single tool hooked up to illustrate our playground.
- Basic Assistant UI design - copied from their site as much as possible

### Out of Scope:

- Evaluations - I'll dedicate an entire iteration to this.
