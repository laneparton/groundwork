# Project vision

I've long needed a place to document learned experiences outside of work. This is my sandbox - where I'll document the lessons I've already learned or want to understand.

## Mission

Build a working agent harness on AI SDK for querying data inside a data warehouse through natural language. Use a complete web application to demonstrate how the harness provides context, guides tool use, handles failures, and produces answers grounded in query results.

Start with a vanilla agent, evaluate it against real tasks, and make improvements measurable so developers can understand and reuse the resulting design.

## Practical promise

The project must run as a working application.

A developer should be able to clone the repository, run the application, and ask the agent questions against real data. They should be able to run its evals and follow a request through the React interface, backend agent, and tool calls.

A developer should leave with a real warehouse-querying harness they can reuse, evidence of how it improves on the baseline, and an understanding of why it makes these choices.
